- `slides/`：本讲课件 PDF。

- 每讲 `README.md`：日期、讲师、录像链接（如有）和完整资料目录。
- 重复出现在多讲的论文在各讲分别保留，便于独立阅读。
- 未发布材料的课程保留空位说明，不猜测或补造链接。

本次保存 224 份 PDF（含各讲重复副本），其中 slides 15 份；每份 PDF 均检查文件头、结束标记及页数可读取。
